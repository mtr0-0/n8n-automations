Featured project: AI Personal Sales Assistant (Lead Whisperer)

This profile highlights a small collection of n8n automations I built. The AI Personal Sales Assistant:
- Collects leads from website forms
- Saves leads to Google Sheets
- Uses an LLM to qualify leads and generate a suggested email reply
- Sends the reply via Gmail and posts a summary to Slack
